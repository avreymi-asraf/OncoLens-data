# Project Data Sphere

De-identified patient-level data from late-phase oncology trials, mostly **comparator arms**. Free, light approval. FDA external-control-arm program (SCLC, GBM). **Use:** clean, protocol-defined endpoints (PFS, OS, adverse events per CTCAE) to test survival / toxicity models; trial patients differ from real-world patients (healthier, selected). Verify current terms.
